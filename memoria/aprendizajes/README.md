# Aprendizajes

Lecciones documentadas por los agentes tras cada producto terminado (regla 7). Se escriben **solo vía PR revisado**, nunca directamente.

## Qué va aquí

Un archivo por producto, con al menos:

- Qué funcionó.
- Qué antipatrón apareció.
- Qué se haría distinto.

## Para qué sirve

Alimenta a los agentes futuros: antes de proponer o construir, un agente debería poder leer lo que la fábrica ya aprendió sobre problemas parecidos.

Los ADRs viven en `docs/adr/`; esta carpeta los referencia cuando aplica, no los duplica.
